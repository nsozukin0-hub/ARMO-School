# 📡 Настройка вебхука для MAX API Platform

## ✅ Статус проверки

- **Токен бота:** Валиден (получает 404 на неизвестные endpoint'ы, что нормально)
- **MAX API URL:** `https://platform-api2.max.ru`
- **URL вебхука:** `https://armo-school.vercel.app/webhook`

## 🔧 Как настроить вебхук

### Вариант 1: Через Личный Кабинет MAX API Platform (РЕКОМЕНДУЕТСЯ)

1. Откройте Личный Кабинет разработчика:
   👉 **[https://dev.max.ru/dashboard](https://dev.max.ru/dashboard)**

2. Перейдите в раздел вашего бота

3. Найдите секцию **"Webhook"** или **"Вебхук"**

4. Укажите URL вебхука:
   ```
   https://armo-school.vercel.app/webhook
   ```

5. Сохраните изменения

6. Проверьте статус вебхука в личном кабинете

### Вариант 2: Автоматически через скрипт

```bash
python set_webhook_manual.py
```

Этот скрипт проверит токен и покажет инструкцию.

## 🧪 Тестирование после настройки

После настройки вебхука в личном кабинете:

1. **Отправьте команду `/start`** вашему боту в MAX мессенджере

2. **Проверьте логи приложения** на сервере (Vercel):
   - Зайдите в панель управления Vercel
   - Откройте логи деплоя
   - Ищите POST запросы на `/webhook`

3. **Убедитесь, что бот отвечает корректно**:
   - Должно появиться главное меню с кнопками
   - Бот должен представиться

## 💡 Примечания

### HTTPS требование
- Вебхук должен быть доступен по **HTTPS**
- Vercel автоматически предоставляет HTTPS сертификаты
- URL `https://armo-school.vercel.app/webhook` уже использует HTTPS

### Для локальной разработки

Если вы разрабатываете локально:

1. Запустите бота:
   ```bash
   python main.py
   ```

2. В другом терминале запустите ngrok:
   ```bash
   ngrok http 8000
   ```

3. Используйте полученный URL ngrok:
   ```
   https://abc123.ngrok.io/webhook
   ```

4. Настройте этот URL в личном кабинете MAX API Platform

### Структура webhook payload

MAX API Platform отправляет POST запросы со следующей структурой:

```json
{
  "update_id": 12345,
  "message": {
    "message_id": 67890,
    "from": {
      "id": "user_id",
      "username": "username"
    },
    "chat": {
      "id": "chat_id"
    },
    "text": "/start",
    "date": 1234567890
  }
}
```

Или для callback query:

```json
{
  "update_id": 12345,
  "callback_query": {
    "id": "callback_id",
    "from": {
      "id": "user_id"
    },
    "data": "menu_schools",
    "message": {
      "message_id": 67890
    }
  }
}
```

## 🛠️ Troubleshooting

### Вебхук не работает

1. **Проверьте URL**: Убедитесь, что URL правильный и доступен
   ```bash
   curl -I https://armo-school.vercel.app/webhook
   ```

2. **Проверьте логи Vercel**: 
   - Зайдите в [vercel.com](https://vercel.com)
   - Выберите ваш проект
   - Посмотрите Deployment Logs

3. **Перенастройте вебхук**:
   - Удалите текущий вебхук в личном кабинете
   - Добавьте заново

### Бот не отвечает

1. **Проверьте токен**: Убедитесь, что `BOT_TOKEN` в `.env` правильный

2. **Проверьте базу данных**: 
   ```bash
   ls -la school_bot.db
   ```

3. **Перезапустите приложение**:
   - В Vercel: Redeploy
   - Локально: перезапустите `python main.py`

### Ошибки 404 от MAX API

Это **нормально**! MAX API Platform имеет специфичные endpoint'ы, которые отличаются от стандартных. Главное, чтобы:
- Токен не возвращал 401 (Unauthorized)
- Вебхук был настроен через личный кабинет
